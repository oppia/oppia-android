# Certificate

This directory holds the **public certificate** used by `SignReleaseBinary.kt` to verify that an AAB was correctly signed by Oppia's Cloud KMS key.

## File

| File | Description |
|---|---|
| `oppia_release_signing_cert.pem` | Public certificate exported from Cloud KMS after the signing key is created |

## How to Add the Certificate

The certificate is generated by org admins during the GCP setup (see `docs/release/gcp-setup-instructions.md`, Step 4). This is a **one-time setup step** — the certificate only needs to be regenerated if the signing key is rotated. Once the Cloud KMS key is created, run:

```bash
gcloud kms keys versions get-public-key 1 \
  --location="global" \
  --keyring="oppia-android-release-keyring" \
  --key="oppia-android-signing-key" \
  --output-file="oppia_release_signing_cert.pem" \
  --project=<GCP_PROJECT_ID>
```

Then commit `oppia_release_signing_cert.pem` to this directory via a PR.

## What This File Is NOT

- This is the **public** certificate only — it contains no private key material.
- The **private signing key** never leaves Google Cloud KMS (HSM boundary). It is not stored here or anywhere in the repository.
- Do not commit any `.p12`, `.jks`, or private key files to this directory.
